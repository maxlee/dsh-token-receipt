# Bundled fonts

The Token receipt bundle embeds two open-source font files in `client.js` as
base64 data URLs so the receipt looks the same on every machine:

- **Inter** — Copyright (c) 2016 The Inter Project Authors. SIL Open Font License 1.1.
  License text: [licenses/Inter-OFL.txt](licenses/Inter-OFL.txt)
- **JetBrains Mono** — Copyright 2020 The JetBrains Mono Project Authors. SIL Open Font License 1.1.
  License text: [licenses/JetBrainsMono-OFL.txt](licenses/JetBrainsMono-OFL.txt)

Both fonts permit embedding and redistribution under the SIL Open Font License 1.1.
